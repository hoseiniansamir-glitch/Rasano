# رسانو (Rasano)

ویرایشگر ویدئوی حرفه‌ای اندروید، طراحی‌شده برای انتشار در **کافه‌بازار** — محصول «ثامر آی تی».

## معرفی

رسانو یک ویرایشگر ویدئوی چندلایه است که تمام پردازش روی دستگاه انجام می‌دهد:

- **سه لایهٔ ویدئو/تصویر (V1/V2/V3)** با جابه‌جایی، بزرگ/کوچک‌سازی و چرخش مستقل هر کلیپ
- **کات (Split)** در هد پخش و **برش (Trim)** با دستگیره‌های زندهٔ تایم‌لاین
- سرعت پخش ۰٫۲۵x تا ۴x با حفظ صدا، افکت‌های صوتی مستقل هر کلیپ (اکو/ریورب/اکولایزر/8D)
- لایه‌های صوت مستقل (A1..An) با نمودار موج و جابه‌جایی زمانی
- متن و استیکر (T1) با فونت فارسی، کروماکی، ضدلرزش (Stabilizer)، فیلتر و تنظیم رنگ
- پشتیبانی GIF متحرک، حرکت Ken Burns برای تصاویر ثابت
- خروجی MP4 با موتور تکه‌ای (Chunked) — مصرف حافظهٔ ثابت مستقل از طول پروژه

## وضعیت سورس در مخزن

در این مخزن **تمام فایل‌های متنی سورس** (Kotlin، XML، Gradle، اسناد) نگهداری می‌شود. فایل‌های دودویی توسط رابط افزونهٔ GitHub قابل پوش نیستند و به‌صورت بستهٔ کامل در `Rasano-A29.0-DEV3-source.zip` تحویل داده شده‌اند؛ فهرست آنها در `docs/SOURCE-STATUS.md` آمده است:

- ۲۵ فایل PNG (آیکون لانچر، آیکون پیام‌رسان‌ها، واترمارک)
- `signing/socialshare.keystore` (عمداً بیرون از مخزن — رمز امضا نباید در مخزن باشد)
- `local.properties` (وابسته به ماشین ساخت)

## ساخت از سورس

```bash
# پیش‌نیازها: JDK 17 (Temurin)، Android SDK (platform 35، build-tools 35)
gradle assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

- `minSdk 24` — `targetSdk/compileSdk 35`
- Kotlin 2.0.21 + Jetpack Compose (BOM 2024.12.01)
- امضای release: keystore محلی با تنظیمات داخل `app/build.gradle.kts`

## نقشهٔ راه

نقشهٔ راه توسعه در سه فاز (پایداری → کیفیت → حرفه‌ای) با ۱۷ تسک شماره‌دار `RM-*` دنبال می‌شود؛ جزئیات کامل در [`docs/ROADMAP.md`](docs/ROADMAP.md) و وضعیت هر تسک در بخش **Issues** همین مخزن نگهداری می‌شود.

- **فاز ۱ — پایداری (هدف A29):** RM-B1…B4، RM-D2، RM-E2، RM-M1
- **فاز ۲ — کیفیت (هدف A30):** RM-C1…C3، RM-D1، RM-E1، RM-E3
- **فاز ۳ — حرفه‌ای (هدف A31+):** RM-A1…A4
